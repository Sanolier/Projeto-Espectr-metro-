O espectrômetro consiste na análise da imagem obtida através da visualização dos comprimentos de onda emitidos por um determinado elemento.
O Projeto aqui proposto, ao ser dado uma determinada imagem de espectro, seja feita uma análise e então o dado dever ser cruzado com o banco de dados do Atomic Spectra, do site Hyper Physics.
Outros bancos de dados serão implementados para cruzamento de informações e aumento da precisão da análise.
